# DEV MODE — Software Developer Playlist

Vercel-ready Next.js playlist with an Old Monk-inspired dark editorial layout.

## Music
Put your MP3s in `public/music/` and edit the `playlist` array in `app/page.js`.

## Office keyboard ambience
Put a real keyboard/office ambience recording at:
`public/sounds/keyboard.mp3`

The **Office sounds** button provides the visual office simulation and is wired to that audio asset.

The Office sounds button is already wired to play/pause the ambience audio.

## Run
npm install
npm run dev

Then deploy the repository to Vercel.
